### Deskripsi Lengkap (Max 4000 karakter)
```text
WhatsApp Cast adalah aplikasi produktivitas ringan untuk menyusun dan mengirimkan pesan siaran (broadcast) secara terpersonalisasi melalui tautan resmi WhatsApp, tanpa risiko pemblokiran nomor akun dan tanpa biaya API tambahan.

Semua data—termasuk template, variabel kustom, riwayat pesan, dan kontak—disimpan 100% secara lokal di perangkat Anda. Tidak ada server eksternal, tidak ada analitik pihak ketiga, dan tidak ada pelacak aktivitas.

FITUR UTAMA:

1. Editor Template Kaya Format
Susun pesan promosi, pemberitahuan tagihan, atau pengumuman komunitas dengan format teks WhatsApp: *tebal*, _miring_, ~coret~, `kode monospace`, serta ratusan emoji terintegrasi.

2. Variabel Dinamis & Nilai Bawaan
Sisipkan variabel {{nama}} untuk memanggil nama penerima, tanggal otomatis (hari ini, besok, lusa, nama hari, nama bulan), serta variabel kustom tanpa batas (seperti {{invoice}}, {{nominal}}, {{jatuh_tempo}}). Nilai bawaan memastikan pesan tetap rapi meski data tertentu belum terisi.

3. Pratinjau Gelembung Chat Interaktif
Lihat tampilan persis pesan dalam format bubble chat WhatsApp sebelum dikirim ke penerima. Pastikan tidak ada variabel kosong sebelum menekan tombol kirim.

4. Antrean Pengiriman Bertahap yang Aman
Kirim pesan satu per satu melalui intent resmi WhatsApp tanpa bot atau otomasi ilegal yang dapat menyebabkan akun Anda diblokir oleh WhatsApp. Lacak progres pengiriman dengan indikator status otomatis.

5. Manajemen Kontak & Grup Hierarki
Kelola kontak penerima dengan label dan struktur grup bertingkat (induk dan subgrup). Dukungan multi-select untuk penambahan label massal atau penghapusan cepat.

6. Impor Kontak CSV & VCF
Impor daftar pelanggan Anda dari file kontak telepon (.vcf) atau spreadsheet (.csv) dengan deteksi pemisah otomatis dan pemetaan kolom cerdas.

7. Cadangan & Pemulihan Fleksibel (Skema 5)
Ekspor seluruh database ke file JSON kapan saja, bagikan antar perangkat, dan pulihkan dengan opsi Gabung (Merge) atau Ganti Semua (Replace). 100% kompatibel dua arah dengan versi web.

8. Mode Gelap & Multibahasa
Dukungan penuh tema gelap (Dark Mode) yang nyaman di mata serta opsi peralihan bahasa instan (Bahasa Indonesia dan English).

JAMINAN PRIVASI & KEAMANAN:
- 0 izin Android sensitif (tidak meminta akses internet latar belakang, tidak membaca SMS, tidak meminta kontak telepon sistem).
- Data Anda adalah milik Anda sepenuhnya dan tidak pernah meninggalkan perangkat.
```

## 2. English (en-US)

### App Title (Max 30 characters)
`WhatsApp Cast` (13 char)

### Short Description (Max 80 characters)
`Safe WhatsApp broadcast via official links. 100% offline, zero backend.` (71 char)

### Full Description (Max 4000 characters)
```text
WhatsApp Cast is a lightweight productivity tool designed to help you compose and dispatch personalized broadcast messages using official WhatsApp links—without the risk of account bans and with zero API subscription fees.

All your templates, custom variables, dispatch history, and contact lists are stored 100% locally on your device. There is no cloud backend, no third-party telemetry, and no behavioral tracking.

CORE FEATURES:

1. Formatted Message Composer
Craft compelling announcements, invoice notices, or greetings with native WhatsApp formatting: *bold*, _italic_, ~strikethrough~, `monospace code`, and a built-in emoji selector.

2. Dynamic Variables & Smart Defaults
Personalize every message with {{name}}, automatic dates (today, tomorrow, weekday name, month name), and custom variables (e.g. {{invoice_no}}, {{due_date}}, {{amount}}). Fallback defaults prevent broken or empty placeholders.

3. Interactive Chat Bubble Preview
Inspect exactly how your message will look inside a WhatsApp chat bubble before sending. Verify that every variable is resolved properly.

4. Safe Sequential Dispatch Queue
Send messages one by one through official WhatsApp intents. No unauthorized automation or background bot engines, ensuring your WhatsApp account remains safe from policy restrictions. Track real-time progress with automated status badges.

5. Contact Management & Nested Groups
Organize contacts into hierarchical groups and sub-labels. Filter recipients with flexible "All / Any" criteria and perform batch label operations.

6. CSV & VCF Contact Import
Quickly onboard recipient lists from standard vCard (.vcf) files or spreadsheets (.csv) with automatic delimiter detection and interactive column mapping.

7. Cross-Platform Backup & Restore (Schema 5)
Export your entire workspace to an offline JSON file. Share or restore backups anytime using safe Merge or Replace modes. 100% bidirectional parity with the open-source web application.

8. Native Dark Theme & Bilingual Support
Clean, modern interface with high-contrast Dark Mode support and instant language toggling between English and Bahasa Indonesia.

PRIVACY & SAFETY:
- Zero sensitive Android permissions required.
- Does not collect, upload, or sell your personal data.
- Works completely offline.

DISCLAIMER:
WhatsApp Cast is an independent productivity utility developed by Ryan Kosegeran. It is NOT an official WhatsApp product and is NOT affiliated with, sponsored by, or endorsed by WhatsApp LLC or Meta Platforms, Inc. The term "WhatsApp" is used strictly for descriptive purposes to indicate link compatibility.
```
